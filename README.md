## 👤 About me

I build on **SAP S/4HANA Public Cloud Edition** the way it is meant to be extended: **Clean Core** inside, **side-by-side** apps outside.
On the stack I work in **ABAP Cloud** and **RAP**, model **CDS Views** for high-performance reporting, and expose business data to external systems through **OData** and **Communication Arrangements**.
Off the stack I ship the apps that consume that data: a native **Kotlin** warehouse app running on **SAP EWM** in two sites, **Python** automation for finance and HR, and **S/4HANA ↔ Salesforce** integration.
Lately I'm connecting LLMs to the ERP through the **Model Context Protocol (MCP)**.

> [!NOTE]
> **Currently**
> - **Systems Analyst @ J.Assy** (Brazilian agtech) since Jan 2026: ABAP Cloud, RAP and side-by-side apps on S/4HANA Public Cloud
> - **Finishing a B.Sc. in Computer Science** at IF Goiano (2022–2026): thesis on receivables & delinquency analytics on S/4HANA Public Cloud
> - **Studying** SAP BTP solution architecture and LLM integration patterns for ERP
> - **Languages:** Portuguese (native) · English (full professional)
