## 👤 Sobre mim

Eu desenvolvo no **SAP S/4HANA Public Cloud Edition** do jeito que ele foi pensado para ser estendido: **Clean Core** por dentro, apps **side-by-side** por fora.
No stack, trabalho com **ABAP Cloud** e **RAP**, modelo **CDS Views** para relatórios de alta performance e exponho dados de negócio para sistemas externos via **OData** e **Communication Arrangements**.
Fora do stack, entrego os apps que consomem esses dados: um app nativo de armazém em **Kotlin** rodando sobre o **SAP EWM** em duas unidades, automações em **Python** para financeiro e RH, e a integração **S/4HANA ↔ Salesforce**.
Ultimamente, venho conectando LLMs ao ERP por meio do **Model Context Protocol (MCP)**.

> [!NOTE]
> **Atualmente**
> - **Analista de Sistemas @ J.Assy** (agtech brasileira) desde jan/2026: ABAP Cloud, RAP e apps side-by-side no S/4HANA Public Cloud

> - **Estudando** arquitetura de soluções no SAP BTP e padrões de integração de LLMs com ERP
> - **Idiomas:** português (nativo) · inglês (profissional pleno)

### Coletor RF de Armazém
<sub>🔒 Corporativo · Privado</sub>

**Problema:** operadores de armazém precisavam de uma coleta de dados RF rápida e confiável no chão de operação, ligada diretamente ao SAP EWM.<br>
**Solução:** app Android nativo em Kotlin, integrado ao SAP EWM para as operações diárias do armazém.
